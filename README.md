# A and K さま トップページ デザイン案

株式会社 A and K さま（www.aandkcorp.com）のリニューアル用トップページ案。
構成は [aandk-proposal](https://github.com/k-matsumoto527/aandk-proposal) の02節・03節に合わせてある。

| 案 | 方向 | URL |
| --- | --- | --- |
| A | 明朝・広い字送り・金茶（エアロファシリティー社を参考） | https://k-matsumoto527.github.io/aandk-design/plan-a.html |
| ― | 過去のお知らせ（全13件） | https://k-matsumoto527.github.io/aandk-design/news.html |

## 案Aの考え方

読み手は**受入企業の採用担当**。かみのて（保育園・放デイ）とは正反対で、
やわらかさや親しみではなく**確かさと品位**で信用を作る。

**エアロファシリティー株式会社（https://www.aero.co.jp/）のサイトを参考にしている**
（ユーザー指定）。参考にしたのは書体・配色・余白の取り方・レイアウトの型で、
**CSSは自前で書いている**（先方のCSSやサブセットフォントは使わない）。

| 要素 | 参考サイト | 案Aでの実装 |
| --- | --- | --- |
| 見出しの書体 | Source Han Serif Light（自社ホストのサブセット） | **Noto Serif JP**（同じ源ノ明朝。Google Fonts） |
| 本文の書体 | 游ゴシック系 | 同じ |
| 差し色 | `#b39861`（金茶） | 同じ |
| ヘッダー | 2段・ロゴ中央・ナビ左右振り分け・上段に対象者別リンク | 同じ型 |
| ヒーロー | 全幅写真＋右下に明朝の欧文＋和文コピー | 同じ型 |
| お知らせ | ヒーロー下端に半透明の帯を重ねる | 同じ型 |
| ボタン | 平行四辺形（skew） | 同じ（中身を逆skewして文字はまっすぐ） |

字送りを広く取る（見出し `.14〜.22em`）のが、この方向のいちばんの肝。

## 旧サイトの情報は全件を引き継いでいる

**お知らせは13件すべて、本文・写真ごと `news.html` に移してある**（旧サイトの
`/news` は1ページに全件を並べた作りで、ページ送りも記事個別ページも無い）。
記事に貼られていた写真4枚（HANDS OF GOD保育園の卒園式・新聞掲載記事）も
`img/news/` に取り込み済み。トップの帯は直近3件を出し、「Read more」で一覧へ。

`news.json` の生成手順は下の「お知らせの引き継ぎ」を参照。

## 素材はすべて旧サイトから流用している

| ファイル | 元 | 使い方 |
| --- | --- | --- |
| `img/logo-mark.jpg` | 旧サイトのロゴマーク | ヘッダー。社名は隣にテキストで出すので文字なしのマークだけを使う |
| `img/logo.png` | 旧サイトのロゴ（文字入り） | 予備。いまは未使用 |
| `img/hero-trainees.jpg` | `main_20190910.jpg` | ヒーロー。**上部に焼き込まれた文字を切り落としてある**（y=122から428px） |
| `img/training-1.jpg` `training-2.jpg` | `IMG_1274` `IMG_2413` | 提携機関カード |

保育園の写真（`main_202207` `2.jpeg` `mainimage_hog`）は**このサイトでは使わない**
（外国人材に絞る方針のため）。必要になったら旧サイトから取り直せる。

## ハマった点

- **社名と添え書きを `<span>` のままにしてインラインで流れ、ナビに重なった**。
  `.brand .txt` を flex-column にし、`.nm`/`.sub` を block にする。電話番号も同じ。
- **ヘッダーを畳む幅は 1080px**。畳む指定はレイアウトの折返し（1000px）と
  **別の @media に分ける**。まとめると中間の幅が意図せず1カラムになる。
- **ロゴは幅186px。** 112pxだと `logo.png`（400×78の横長ロックアップ）の
  社名が読めない。参考サイトのロゴは縦組みなので同じ寸法では通らない。
- **★ヒーローの文字の可読性は、要素の実座標を取ってから測ること。**
  目分量のy座標で測って「2.92:1で不足」と誤診した。右寄せの文字なので、
  文字の無い左半分を測っていたのが原因。`kmtest/_ak_rect.html` で
  `getBoundingClientRect` を出させてから、その矩形だけを測る。
  実測値＝欧文 10.58:1／和文 12.49:1（どちらも白文字・WCAG AA以上）。

## 検査

390 / 600 / 768 / 1020 / 1021 / 1200 / 1440px で横あふれなしを確認済み。

## お知らせの引き継ぎ

旧サイトの `/news` は **1ページに全件が並ぶ作り**（ページ送りも記事個別ページも無い）。
記事は「日付だけの行で始まる `<p>`」＋その後ろのギャラリー、という構造。

抜き出しの注意:
- **同じ記事が2回出てくることがある**（2020.05.25 と 2019.09.06）。日付＋見出しで重複を除く
- 日付の表記が `2021/8/30` と `2021年3月28日（日）` の2種類ある
- 本文に `<wbr>` が挟まっているので、タグを剥がしてから結合する
- 画像は `/application/files/...` の絶対パス。`http://aandkcorp.com` を前置いて取得する

`news.html` は `plan-a.html` の `<head>`〜`</style>`・ヘッダー・フッターを
そのまま流用して組み立てている。**案Aのデザインを変えたら news.html も作り直すこと。**
