# A and K さま トップページ デザイン案

株式会社 A and K さま（www.aandkcorp.com）のリニューアル用トップページ案。
構成は [aandk-proposal](https://github.com/k-matsumoto527/aandk-proposal) の02節・03節に合わせてある。

| 案 | 方向 | URL |
| --- | --- | --- |
| A | きっちり（濃紺・細い罫・整列重視） | https://k-matsumoto527.github.io/aandk-design/plan-a.html |

## 案Aの考え方

読み手は**受入企業の採用担当**。かみのて（保育園・放デイ）とは正反対で、
やわらかさや親しみではなく**確かさ**で信用を作る。

- 写真に頼らない。ヒーローは濃紺＋薄い罫のグリッドで「整っている」印象を出す
- **登録支援機関の番号を最上部の帯とヒーローの2か所に出す**（信用の要）
- 数字・支援10項目・流れ5段階を、罫線で区切って整列させる
- 丸みと影を使わない（角丸0・box-shadow無し）。差し色は金茶 `--gold #b07d2e` のみ

## ハマった点

- **社名と添え書きを `<span>` のままにしてインラインで流れ、ナビに重なった**。
  `.brand .txt` を flex-column にし、`.nm`/`.sub` を block にする。電話番号も同じ。
- **ヘッダーを畳む幅は 1140px**。`.wrap` が 1080px 上限なので、これ未満だと社名が
  「株式会社 A and…」と省略される。**目視ではなく `kmtest/_ak_head.html` で実測して決めた**
  （社名→ナビの間隔・社名の省略有無を幅ごとに出す）。
- **畳む指定はレイアウトの折返し（1020px）と別の @media に分ける**。
  まとめると 1021〜1139px が意図せず1カラムになる。

## 検査

390 / 600 / 768 / 1020 / 1021 / 1200 / 1440px で横あふれなしを確認済み。
